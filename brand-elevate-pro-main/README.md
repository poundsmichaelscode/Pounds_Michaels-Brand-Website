# Pounds Michaels Digitals – Digital Agency Landing Page

A modern, premium, and conversion-focused digital agency landing page built for **Pounds Michaels Digitals**. This project showcases services, brand identity, and lead-generation features using modern web technologies and best practices for performance and SEO.

🔗 **Hosted on Vercel:**

## ✨ Features

* Premium, modern UI with gold-on-black branding
* Fully responsive (mobile-first design)
* Smooth animations using Framer Motion
* WhatsApp chat integration (floating & CTA buttons)
* Conversion-optimized sections (Hero, Services, CTA)
* Consultation form ready for backend/API integration
* SEO-friendly structure with clean Next.js App Router

---

## 🧱 Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Deployment:** Vercel

## 🛠️ Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/pounds-michaels-digitals.git
cd pounds-michaels-digitals
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Run the Development Server

```bash
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

---

## 📦 Build for Production

```bash
npm run build
npm start
```
